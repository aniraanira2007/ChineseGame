# Character asset credits

## Anime Female Mage Character Version 1.0

- Creator: Dawn to Dusk Games.
- Source: https://dawn-to-dusk-games.itch.io/3d-anime-female-mage-character
- License: Creative Commons Zero v1.0 Universal (CC0), as listed on the source page.
- Imported file: `anime-female-mage/anime_female_mage.glb`.
- The free Tier 1 archive also contains an FBX and separate texture PNGs. The project uses the GLB plus resized 1024 px WebP versions of its five color maps; the FBX is not served by the website.
- The model includes an authored idle and run clip. Walk reuses the run clip at a slower playback rate. Jump and landing are driven by the existing world controller with simple avatar pose feedback; wave, sit, dance, and celebrate use lightweight procedural poses because the GLB does not include matching named clips.

## Speen Anime Boy VRM

- Creator: Manuel Spinelli / NoobCalledSpeen.
- Source: https://sp-entertainment.itch.io/anime-boy-model.
- Permission: the creator's itch.io page says people who download the model there have permission to use it. The embedded VRM metadata allows commercial use and marks standalone redistribution as prohibited; keep the asset bundled only as part of the game and do not resell the raw model.
- Imported file: `kai-anime-boy.vrm` (VRM 0.x container; loaded through Three.js GLTFLoader).
- The model is rigged but has no authored animation clips. Kai uses procedural humanoid bone motion for idle, walking, running, jumping, landing, and waving in this project.
